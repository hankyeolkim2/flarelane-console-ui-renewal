# 분석 보드 — 스테이징 동작 메모 (2026-10-08)

스테이징 콘솔 번들 코드와 화면에서 읽은 동작. 프로토타입은 이 동작과 똑같이 만들고, 모양은 Figma 시안을 따른다.

## 주소
- 목록 `/analytics-boards`
- 보드 `/analytics-boards/:boardId`
- 통계(리포트) 편집 `/analytics-boards/:boardId/reports/:reportId`
- 새 통계 `/analytics-reports/new?type=INSIGHT | FUNNEL` (보드와 무관하게 열리고, 저장할 때 보드 선택)

## 머리 영역 (목록 · 보드 공통)
- 검색칸 「보드명, 통계명, 이벤트 검색」
  - 입력 후 0.3초 뒤 서버 검색. 결과 = 보드 · 통계 섞인 목록. 바깥을 누르면 닫힘.
  - 결과 줄 = 아이콘(보드는 폴더+, 통계는 인사이트/퍼널) · 이름(없으면 「제목 없음」) · 보조 글(보드 = 「n개의 통계」, 통계 = 속한 보드 이름) · 편집일.
  - 결과 없음 = 「검색 결과가 없습니다」.
  - 누르면 검색어 지우고 보드 또는 통계 편집으로 이동.
- 「생성」(Primary, add + 열림에 따라 keyboard_arrow_down/up) → 메뉴(오른쪽 끝 맞춤)
  - 인사이트(이벤트의 발생 현황과 추이 분석) → `/analytics-reports/new?type=INSIGHT`
  - 퍼널(단계별 전환율과 이탈률 분석) → `…type=FUNNEL`
  - 구분선
  - 보드 → 이름 없는 보드를 바로 생성하고 그 보드로 이동

## 목록
- 제목 「분석 보드」 + 「n개 보드」(현재 탭 기준 전체 개수)
- 탭 전체 / 내가 만든 (스테이징 탭에는 개수 없음 — 시안은 개수 표시)
- 정렬 선택: 최근 편집순(기본) / 최근 생성순
- 표: 보드명(+「n개의 통계」) · 최근 편집일 · 생성자 · ⋯
  - 편집일 = n분 전 / n시간 전 / n일 전 → 그 이상은 YY.MM.DD
  - 생성자 = 이메일 앞부분, 길면 말줄임 + 툴팁. 탈퇴 = 「탈퇴한 멤버」
  - 행 전체 클릭 → 보드로 이동 (이름 수정 중에는 이동 안 함)
  - ⋯ → 이름 수정(행 안에서 바로 입력) · 삭제(빨강)
  - 이름 수정 저장 → 최근 편집순이면 그 행이 맨 위로
  - 삭제 → 확인창 「보드를 삭제하시겠습니까?」 / 「보드 삭제시 보드에 포함된 모든 통계가 삭제되며, 복구 불가합니다.」 → 행 제거 · 개수 −1 · 알림 「{name} 보드가 삭제되었습니다.」
- 처음 10개, 아래 끝에 닿으면 다음 묶음 불러오기(무한 스크롤, 불러오는 동안 뼈대 행)
- 보드 0개 = 빈 화면 「보드를 생성하고 통계를 관리해 보세요.」 + 「보드 생성」

## 기타 문구
- 새 통계 이름: 새 인사이트 / 새 퍼널
- 통계 삭제: 「통계를 삭제하시겠습니까?」(남의 통계면 「내가 생성한 통계가 아닙니다. 삭제하시겠습니까?」) / 「삭제된 통계는 복구 불가합니다.」
- 보드 통계 개수 제한: 「이 보드의 통계 개수 제한에 도달했습니다.」 / 「보드당 최대 {limit}개의 통계를 생성할 수 있습니다. 새 보드를 만들어 통계를 추가해 주세요.」
- 저장: 「저장 완료!」 · 저장 버튼 저장 후 「저장 됨」 · 나가기 확인 「저장되지 않은 변경사항이 있습니다. 페이지를 나가시겠습니까?」
- 보드 선택 모달: 「통계를 저장할 보드 선택」 · 검색 「보드 이름, 생성자 검색」 · 「새 보드 생성」 · 「새로 생성할 보드」 · 「유효하지 않은 이름입니다.」
- 기간: 어제 · 오늘 · 7일 · 30일, 단위: 시간 · 일 · 월
- 결과 빈 상태 「통계 생성을 위해 분석 지표에서 이벤트를 선택하세요.」 + 「인사이트/퍼널 사용 방법 확인하기.」, 불러오는 중 「데이터가 많을 경우 최대 10분이 걸릴 수 있습니다.」, 실패 「데이터를 불러오지 못했습니다.」 / 「문제가 계속될 경우, 문의하기.」 / 「재시도」
- 결과: CSV 추출 · 명/회 · 표(이벤트 · 평균 / 단계 · 모든 단계 · 총 전환율) · 「이탈 {rate}」 · CRM 경고
- 조건 패널: 분석 지표 · 측정 기준(사용자 수 / 총 이벤트 수) · 전환 인정 기간(1~30일 / 1~720시간) · 타겟 유저 · 데이터 그룹(준비중) · 이벤트 추가 · 타겟 그룹 추가 · 선택기 문구(이벤트 검색, 최근 발생 횟수(n일), 속성 검색, 모든 속성, 속성값 검색, 전체 선택, 상위 100개만…, 적용, 측정할 데이터가 없습니다…) · 타겟 선택기 탭(전체 · 이벤트 · 세그먼트 · 유저 · 디바이스) · 필터(속성 선택 · 값 선택 · 값 입력 · 시간 · 값이 비어있음 · "{keyword}"이 들어가는 값 · n개 일치 · is)
